# Инварианты небезопасного кода

| Модуль | Что требует `unsafe` | Инвариант |
| --- | --- | --- |
| `flit-platform-linux-gui/src/symbols.rs` | Открытие библиотек, поиск символов и преобразование адресов в функции | Таблицы привязаны к фиксированным SONAME. Каждая запись задаёт точное имя, ABI, размеры и типы аргументов и результата из заголовка библиотеки. Нулевой адрес отклоняется до преобразования. Таблицы libdbus и Fontconfig загружаются один раз на процесс. Флаг `RTLD_NODELETE` сохраняет код и глобальное состояние библиотек после закрытия дескрипторов загрузчика. |
| `flit-platform-linux-gui/src/dbus.rs` | FFI к libdbus, указатели сообщений, C-строки и итераторы | `DBusError` имеет C-совместимое размещение и инициализируется перед первым вызовом. Буфер итератора сохраняет выравнивание и вмещает C-структуру. Разбор проверяет тип аргумента перед чтением и копирует C-строки до освобождения сообщения. Вызовы получают живое соединение или сообщение. Соединение закрывается и освобождается, сообщение освобождает одну принадлежащую обёртке ссылку, ошибка очищается по завершении. |
| `flit-platform-linux-gui/src/{atspi,gvfs,udisks}.rs` | Прямые вызовы таблицы libdbus и построение контейнеров | Держать API живым дольше соединений и сообщений. Проверять тип перед `get_basic`, передавать адрес C-значения нужного размера, завершать запись контейнера в том же сообщении. Адрес из libdbus действителен пока владелец удерживает сообщение или соединение. |
| `flit-platform-linux-gui/src/fonts.rs` | Вызовы Fontconfig, `mmap`, извлечение строк и массивов из C | Объекты Fontconfig живы во время обращения, строки с нулевым концом принадлежат шаблону, набор шрифтов живёт до завершения обхода. Конфигурация используется для запросов, её время жизни определяется владельцем `Fontconfig`. Отображение шрифта остаётся открытым на всё время жизни выданного среза. Файл отображается для чтения, длина берётся из открытого файла. |
| `flit-platform-linux-gui/src/gl.rs` | EGL/GLES, адрес функции проверки сброса, представление вершин как байтов | Дисплей и конфигурация относятся к одному EGL-устройству. Контекст делается текущим на потоке рендера до вызовов GL, включая чтение статуса сброса. Варианты функции сброса имеют одну сигнатуру. Дескрипторы текстур и буферов принадлежат этому контексту. В шейдер передаются только инициализированные структуры с фиксированной раскладкой, включая явное поле заполнения у `Globals`. |
| `flit-platform-linux/src/inotify.rs` | Создание и регистрация inotify, снятие слежения, опрос | Успешно открытый FD немедленно передаётся одному владельцу `File`. Поток чтения держит свою ссылку на владельца. В `poll` передаётся один живой элемент, в inotify — C-строка и действующий дескриптор. Парсер получает только байты, реально прочитанные в буфер. |
| `flit-platform-windows/src/watcher.rs` | IOCP, `OVERLAPPED`, связанный буфер и асинхронная отмена | Один запрос на слот. Буфер и структура размещены в отдельных стабильных аллокациях. Даже если отмена сообщает, что запрос завершён, содержимое слота освобождается после извлечения его пакета из порта. Новый запрос использует буфер после завершения предыдущего. Порт удерживается до выхода потока. Разбор ограничен длиной, которую вернул IOCP, и вместимостью буфера. |
| `flit-platform-windows/src/fs.rs` | NT-выдача каталога, свойства, дескрипторы и чтение системных записей | Синхронные объекты открыты с правами для вызова, строки заканчиваются нулём либо передаются с указанной длиной. Для выдачи NT буфер выровнен по `u64`, принадлежит текущему потоку и читается после успешного вызова. Поля и смещения берутся из записей формата, запрошенного у NT. |
| `flit-platform-linux/src/lib.rs` | `time` и `localtime_r` | При успешном вызове локальное время записано в принадлежащий текущему потоку `libc::tm`. Смещение читается после проверки возвращённого указателя. |
