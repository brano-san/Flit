## New

- On Windows, Paste As creates shortcuts, symbolic links, junctions and hard links through the operation queue, with conflicts, cancel and one administrator prompt for a whole batch of symbolic links.
- On Windows, ordinary files and folders show the icon overlays of shell extensions such as TortoiseGit, TortoiseSVN and Dropbox. Overlays are asked only for visible rows on local fixed drives and refresh when a file changes or the folder is refreshed.
- On Windows, Details sorts and groups by Dimensions, Length, Contributing artists and File version, reading every file in the background, and adds Date taken, Camera model, Album, Title, Authors and Company columns.
- Files can be added to 7z, TAR and TAR.GZ archives, keeping the existing contents and the archive's access rights.
- Repository panes show Git commit hashes, create and delete branches with confirmation for unmerged commits, show an ongoing merge, rebase or cherry-pick with a confirmed abort and conflict selection, and Git Sync pulls before pushing.
- On touch screens a finger scrolls the sidebar, the Inspector, Columns, Tree, Settings, long context menus and search results with the same glide as the file list. On Linux a held finger opens the context menu and two fingers pinch to zoom.
- On Linux, video plays inside the Inspector through libmpv when it is installed, drawn at the pane's size up to 720p with the Play button, seek bar and volume. Without libmpv the separate mpv window and the other players work as before, and About names the libmpv package to install.
- On Linux, connecting to an smb, sftp or WebDAV server that needs a login asks for the user name, domain and password, and answers host-key questions, in a Flit dialog. The password can be kept until logout and is never stored by Flit.
- On Linux, folders show their own icons from `.directory` files and Nautilus, the user folders such as Pictures and Downloads show their theme icons, links and unreadable files show emblems, and files without an extension get an icon by their content.
- On Linux, window buttons follow the GNOME or KDE layout and update without a restart, and trusted `.desktop` launchers show their application names.
- On Linux, links, text and pictures dropped into Flit are saved through the operation queue.
- On X11, a tab dragged to another Flit window shows where it will land.
- The Inspector highlights Makefiles, Dockerfiles and CMake files, recognises names such as Gemfile, Jenkinsfile, PKGBUILD and `.bash_profile`, and highlights scripts without an extension by their shebang.
- New in the context menu shows the icon of each file type and always offers a text document.

## Changed

- Pictures show thumbnails in every view whose icons are 32 px or larger, including Details and List at the largest size.
- Scrolling past the last item is on by default.
- The Inspector's dock bar shows only while the Inspector has focus and is drawn like a panel's, and a click anywhere in the Inspector focuses it. An Inspector below the files is resized from its own top edge.
- Windows system errors follow Flit's interface language.
- On Linux, missing helper programs name the distribution package to install, and FUSE shares unmount with fusermount3.
- On Linux, taskbar progress no longer starts a gdbus process for every step.

## Fixed

- A Windows shell extension that stops answering no longer leaves every later context menu without Open with and the other Windows items, or with grey placeholder rows.
- On Linux, Open in Terminal opens Ghostty, and terminals chosen through xdg-terminal-exec, in the selected folder.
- Adding files to an archive reached through a symbolic link updates the real archive instead of replacing the link.
- On Linux, file icons are no longer read from network or virtual mounts, and a slow file no longer holds up other icons.
- On Linux, launcher names follow renames and trust changes at once, and switching KDE back to Breeze icons is followed.
- On Windows, symbolic links keep plain target paths, and a refused administrator prompt shows as an error.
