## New

- File operations report each failed item as it happens, with Retry, Skip, Skip all and Cancel. A full disk asks Retry or Cancel.
- Right-button drag shows a Copy here, Move here, Create link here menu on drop, including drags that come from other programs.
- Closing a window or quitting while copies, moves or deletes are running asks before cancelling them.
- The system does not go to sleep while file operations run.
- Text fields have undo and redo (Ctrl+Z, Ctrl+Y, Ctrl+Shift+Z).
- Hovering a file shows a tooltip with its full name when it is cut off, or its type, size and modification date. This also works in the parent panes of the Columns layout.
- Rename blocks characters the destination does not allow while you type, and keeps the editor open with an explanation when a name is taken or the rename fails.
- Windows: pasting and dropping from sources without plain files works: items inside zip folders, phones, the Recycle Bin, Outlook attachments and messages, and links dragged from a browser, which are saved as `.url` files.
- Windows: localized names of special folders such as Documents and Downloads are shown in the list, breadcrumbs, tabs and sidebar.
- Windows: cloud placeholders such as OneDrive online-only files are no longer downloaded by the preview, thumbnails or hashing. They show a cloud mark and a "Download to preview" button.
- Linux: Flit asks for administrator rights through polkit when an operation needs them, instead of failing.
- Linux: Properties can change permissions, owner and group, optionally for enclosed files, with undo.
- Linux: an AppImage or program without the execute bit offers to allow executing and run it. Executable programs and AppImages run directly when opened.
- Linux: Run in terminal for executable files.
- Linux: Open with offers Other application, a custom command and setting the default application.
- Linux: symbolic links (Create link, Paste link, New link), Flatten folder and tags on local file systems.
- Linux: when items cannot be moved to the Trash, Flit offers to delete them permanently.
- Linux: Ctrl+Q quits every window. Linux has its own default shortcuts: F9 for the sidebar, Alt+Home for home, Alt+1 to Alt+9 for tabs, Ctrl+1 to Ctrl+3 for views, Ctrl+D to pin a folder and Ctrl+Shift+I to invert the selection.
- Linux: the address bar accepts `~`, `$HOME`, `trash:` and server addresses such as `smb://` and `sftp://`.

## Changed

- Single-click opening of folders happens on mouse release, so the item can still be dragged.
- Double-clicking a column edge fits that column to its contents.
- After a delete, focus moves to the neighbouring item.
- Linux: cut and copy work with Nautilus, Dolphin and other file managers in both directions, without needing wl-clipboard or xclip.
- Linux: apps opened from Flit, and Flit itself when raised again, get focus on Wayland.
- Linux: Open with only lists applications that handle the file type or its parent types, honours TryExec, OnlyShowIn, NoDisplay and Path, and shows application icons.
- Linux: Open in terminal opens in the selected folder for GNOME Terminal, Ptyxis, Console, Konsole, kitty, Alacritty, foot, WezTerm and other terminals.
- Linux: copying to FAT and exFAT drives checks the 4 GB file limit before writing and replaces characters those drives do not allow.
- Linux: mounting a drive can ask for a password.
- Linux: the local search index is shown as normal rather than as an error.

## Fixed

- F2 followed by Enter without changes on several selected items no longer renames them all.
- Ctrl+Z and Ctrl+Y in the filter box no longer undo or redo file operations.
- Ctrl+C or Ctrl+X in a text field with nothing selected no longer clears the clipboard.
- Ctrl+drag of an already selected item drags the selection instead of deselecting it.
- Windows: files extracted from downloaded archives keep the Mark of the Web, so SmartScreen and Office Protected View still apply.
- Linux: PNG and WebP previews in the Inspector work, including images whose extension does not match their content.
- Linux: Properties from the sidebar and Home page open.
- Linux: searches containing `word:value` no longer report that Windows Search is unavailable.
- Linux: library commands no longer appear in the sidebar menus, where they could not work.
- Linux: Exec lines with `%f` or `%u` open every selected file.
