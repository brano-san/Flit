## New

- Copies Flit unpacked from archives into the temporary folder are removed at start once they are a day old.
- Property strings for the link target and the security group are defined once, after the Linux and Windows work both added them.
- Getting access to a denied folder on Windows runs icacls from the folder Windows reports as its system folder, not from a path the environment could redirect.
- Details view on Windows offers Dimensions, Length, Contributing artists and File version columns, read from the shell for the visible files in the background.
- Copying or dragging files out of an archive unpacks them to a temporary folder first so other programs can open them, and copied phone items go on the clipboard as shell items.
- Mail, zip-folder, phone and web-link drops are saved by a queued operation that shows in the operations panel, selects what it made and reports its errors.
- Files dropped on a shortcut, a Python script or any other file with a shell drop handler go to that handler, and a file without one still takes the drop into the folder.
- Shortcuts, symbolic links and junctions show the shell's link arrow on their icons, together with any other overlay the shell gives such items.
- Properties on Windows offer Read-only and Hidden boxes for the selected items and an Unblock box for files downloaded from the internet, applied by OK through the operations queue.
- Properties and the Details pane show whether an item is a symbolic link, a junction or a hard link, with the link target or the number of hard links.
- Names with accented letters sort next to their base letter (Ä with A, Ł with L, Ё with Е) and Ukrainian, Belarusian and Serbian letters take their alphabet place, in both case modes.
- Several selected items can be renamed at once in a Batch Rename dialog with find and replace (match case optional, extensions kept), numbering after or before the name from any start, a live preview of the new names, and a clear refusal of empty, invalid, duplicate or taken names.
- When a file cannot be deleted, moved or copied because another program has it open, the question and the error name that program (Restart Manager on Windows, open files in /proc on Linux).
- Paste with no files on the clipboard saves a copied picture as "Pasted image.png" or copied text as "Pasted text.txt" in the folder, numbered when the name is taken, like Nautilus.
- The name conflict dialog also offers Skip identical (same size and date, the rest is still asked about) and Replace older (only items the source has newer) for all remaining conflicts, both also as defaults in settings, and says when two files look the same.
- On Linux emoji are drawn in colour from the installed colour emoji font (COLR, CBDT, sbix), faded with the text but never tinted, while letters and symbols that plain fonts have stay monochrome.
- On Linux executables without an extension show the program icon, USB sticks, optical discs and network mounts show icons of their kind, and switching the GNOME icon theme redraws the file icons without a restart.
- On Linux the Browse rows in Settings (background image, startup folders, settings import) open the desktop's file chooser through the FileChooser portal.
- On Linux previews of EPUB, ODT, RAW and other files come from the installed system thumbnailers, and thumbnails Flit generates are saved in the shared ~/.cache/thumbnails so Flit and other file managers reuse them.
- On Linux Flit's default interface font is the desktop's own (GNOME font-name, KDE font) instead of fontconfig's sans-serif, and full or medium hinting chosen in GNOME or KDE is applied to glyphs.
- Flit takes the system accent colour for selection, focus and highlights and grows with the system text size on Windows (Accent palette, Make text bigger) and Linux (portal accent-color, KDE AccentColor, GNOME text scaling on Wayland), on top of the user's own scale and colours, which stay unchanged.
- On Linux a folder without live updates shows a warning in the status bar, and when the inotify watch limit is the cause one click raises it through pkexec (kept across reboots in /etc/sysctl.d) and reloads the affected tabs.
- On Linux the built-in New menu entries (empty file, text and Markdown documents, shell script) and the names they create follow a language change without a restart.
- On Linux the System date format follows the desktop locale's short date and time (LC_TIME), and the C locale keeps ISO dates.
- Sidebar, home and go-to icons are fetched anew when the icon theme or a folder icon changes, instead of keeping the old picture.
- French and Ukrainian Git messages use the typographic apostrophe like the rest of their translations.
- The Linux search index takes at most an eighth of the inotify limit and no more than 16384 folder watches, leaving room for editors and sync tools.

- On a touch screen a finger drag scrolls the file list and a flick keeps it gliding instead of drawing a rubber band, a tap still selects, Windows hands finger pans to Flit, and Linux passes touches on as touch input.

## Fixed

- A folder that cannot be opened for lack of permission offers Continue, which grants the user read access as an administrator (UAC on Windows, pkexec and setfacl on Linux) and lists the folder again.
- Running copies, moves and deletions can be paused and resumed from their row in the Operations panel or its menu, also on WSL and for elevated Linux operations; a paused operation shows Paused, holds the taskbar progress and no longer keeps the system awake.
- On Windows deleting, renaming or moving a file that a preview handler or the media player shows first closes that preview in every window, so the file is no longer in use, and the preview comes back when the operation ends if the file is still there.
- When the destination is short of space Flit asks on both systems, even with a default conflict action, with Copy anyway, Retry (measures the free space again) and Cancel, and on Linux a move to another device checks the free space before it starts.
- Linux Settings no longer list Windows-only options (long paths, system files, NTFS streams, the stream menu item, the shell submenu), and help that named Windows places and programs describes the Linux behaviour instead.
- Right-clicking the column header after the last column offers the header menu, rows light up and take clicks only under the columns when the table ends before the pane edge, and Always Fit no longer refits a sized Name on every folder load.
- Mounting a disk image on Linux goes through the udisks module, so the image mount and the new drive handling build together again.
- On Linux, files dropped on an executable program, script, AppImage or .desktop launcher are passed to it, and a Windows .exe there no longer pretends to take them.
- On Linux, Size on disk in Properties adds up the blocks files really take, so sparse files, compressed and inline btrfs files are no longer counted as whole blocks of their full size.
- Copies and links made inside a WSL distribution get names in Flit's language, copies on Linux use the localized " - Copy" suffix, and Linux errors from the WSL agent show names such as EIO instead of 0x0000000D.
- Reopening a closed tab, from the shortcut or from Search Tabs, brings back its Forward history, scroll position, selection and focus along with its folder and Back history, and a tab reopened next to another one no longer hands its history to the last tab.
- On Linux the index watches the home folders with inotify, so new, removed and edited files there reach search at once, and the 15-minute refresh rereads only the unwatched folders in place instead of walking every volume again.
- Dragging a maximized window across monitors with different scaling no longer stretches it over every monitor: a DPI change leaves a maximized window alone and keeps any other window inside its monitor, and a saved window size larger than its monitor is cut down at start.
- Copying files on Wayland no longer closes Flit: the clipboard data devices are made once and kept, so the compositor's offer to a just-released device no longer breaks the connection.
- The multi-failure summary fills its translated placeholder again.
- The system animation setting no longer overrides Flit's own Animations option, Back restores the scroll of a folder left with nothing selected, taskbar progress initialises the taskbar list once, Linux sends launcher progress in five-percent steps, and the Undo button keeps its room in a narrow status bar.
