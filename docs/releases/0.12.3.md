## Menus and navigation

- Panel quick commands and built-in context menu commands use icons that match their actions. Right-clicking a file clears the highlight on the panel’s quick commands button.
- Toggling a command’s visibility in Context menu settings keeps the row in place.
- Folder context menus group opening in the current tab, a new tab, a new window, or a split pane under **Open in**. On Windows, Flit omits its terminal command when an enabled Windows Shell terminal command is available for that folder.
- Drag Quick Access group headers to reorder them. An insertion line shows where the group will land, and Flit remembers the new order.
- Drive cards on Home use the theme’s hover highlight, keeping drive names and capacity labels readable.
