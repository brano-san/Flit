## New

- Optional Git integration in settings, disabled by default.
- Extract and delete archive: Smart extraction followed by moving the archive to the trash only after successful extraction. Errors, cancellation and skipped entries preserve the archive.
- Reorder Places by dragging or menu commands, hide individual entries and restore their order and visibility.

## Changed

- Copy and move operations recalculate statistics for affected folders while preserving cached results for unchanged entries. Pending statistics show loading indicators; hiding all statistics columns cancels their calculation.
- Quick Access hides its filter field by default; Alt+F opens it temporarily. File and sidebar icons are larger, dot-prefixed entries are dimmed, and the active tab has a separator outline.
- Open with is promoted into the main Windows file context menu. Linux offers installed file-opening applications when no associated application is found.
- Narrow Details views keep unrelated column widths stable while resizing. Expanding a context menu keeps its position and scrolls when space runs out.
- Selection boxes draw above previews and animate without restarting. Adaptive updates its layout after loading completes and shows the same size line as the corresponding explicit icon view.
- Empty Tags headers remain available. The view menu no longer includes the increase/decrease item-size commands.
- Linux fixes include visible drag feedback, current-folder properties, and Ctrl+F no longer inserting an extra character.
- Linux folder-statistics preferences distinguish HDDs, SSDs and mounted network locations, including partitions and device-mapper backing devices.
- The Linux installer reports its stages, handles quoted D-Bus executable paths, and has automated installation and uninstallation checks in CI.
- Saved preferences remain compatible with earlier state files.
