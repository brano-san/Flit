## New

- Separate preferences for calculating folder sizes, nested folder counts and nested file counts, with migration of existing preferences.
- Search result menus now offer Open, Open file location, Open containing folder in a new tab, Copy, Copy as path and Copy quoted path.
- Resizable search columns and horizontal scrolling. Tab switches between the current folder and all drives while indexed search is open.

## Changed

- The update dialog keeps its header and action buttons visible while long release notes scroll. Notes wrap without truncation, with formatted headings and indented bullets.
- Update version rows have aligned labels and hover feedback; copy notifications fade without moving the footer.
- The active tab outline has rounded transitions at its base and at the sidebar junction.
- README information has been refreshed and includes screenshots of the dual-pane layout, Inspector and command palette.

## Fixed

- Removed the duplicate New submenu from the Windows folder background menu.
- Linux indexing no longer mixes inode identities across mount boundaries or creates repeating paths. Existing Linux index snapshots are rebuilt automatically.
- Search path reconstruction rejects parent cycles instead of displaying repeated directory components.
- Folder statistics and loading indicators respect each individual calculation preference and visible column.
