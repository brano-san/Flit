## New

- On Linux, servers entered by hand can be kept in the Network view: tick "Add to Network" when connecting to a server, or use "Add server…" in Network. Saved servers show at the top of Network after a restart and connect only when opened. Passwords are never stored.
- On Windows, business OneDrive folders appear in Places next to personal OneDrive, with their organisation's name.
- On Linux, the Scripts menu shows Nemo actions only when their Dependencies and Conditions are met. The checks run in the background, so the menu never waits for them.

## Changed

- On Linux, a middle click in any text field, focused or not, pastes the primary selection where you click, as in GTK and Qt.
- On Linux, light hinting also sharpens synthetic bold text without changing its spacing.

## Fixed

- The video frame and its play, time and seek controls no longer jump up when the preview pane gets focus.
- On Linux, the root terminal uses only the system sudo owned by root and otherwise falls back to the verified pkexec.
