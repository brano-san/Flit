## Changes

- Dropdowns in Settings now match the width of their buttons and open above them when there is too little room below.
- The custom context menu editor and other dialogs now show all available choices in dropdowns. Spacing, inactive pane opacity, and thumbnail cache size also use dropdowns.
- **Files and Folders** has a new setting for **Copy as path**. It can follow the platform default, always include double quotes, or always omit them. The setting also applies when using **Ctrl+Shift+C**.
