## New

- Flit can stay in the notification area after the last window closes, and can start at sign-in. Both are off by default; clicking the icon opens a window with your saved session.
- Settings and About list every change Flit made to your system (sign-in start, Open with entries for archives, the flit: link handler, the Linux file chooser setting) and can undo them all; `flit --unregister` does the same from the command line.
- Archives (ZIP, 7z, RAR, TAR, GZ, LZH, JAR) can be opened with Flit from the Open with menu, without changing the default program.
- Opt-in `flit:` links open folders and saved searches.
- `flit --pick` lets scripts choose files or a save location in a Flit window, and on Linux Flit can be the file chooser for other apps through xdg-desktop-portal (off by default).
- Git: switching branches with local changes offers to carry, stash or discard them; ahead/behind counts, changed lines and stashes show beside the branch; dropping a repository link opens Clone; a failed sign-in to GitHub offers to sign in through Git Credential Manager or gh; Fetch, Pull, Push, Clone and Sync show progress and can be cancelled in Operations.
- Undo restores files that a copy or move replaced, refuses when files changed since, and Undo History lets you undo or redo a single operation or dependent operations together.
- Permanent deletion is instant: items disappear at once and are removed in the background, and an interrupted deletion is finished, or undone, at the next start.
- Before a copy or move starts, one review lists every name it would replace, with folders merged by default.
- A running copy or move can be limited to a chosen speed.
- On Linux, copies to USB sticks and other removable or rotating drives are written through, so progress shows what has really reached the drive.
- The Inspector renders SVG, shows camera RAW files from their embedded JPEG, scrolls through every page of a PDF on Linux, and formats JSON, YAML, TOML and XML with a Pretty button. Switching back and forth between two files reuses the previous preview.
- Folder layouts can follow the kind of place (network, removable drive, archive, search) or its content, such as picture folders.
- Ctrl+Tab switches tabs in most recently used order; the palette shows recent and frequent commands; Ctrl+Shift+G turns on quick tags with digit keys.
- The folder filter accepts several masks, exclusions and attributes such as `ext:`, `size:>10M` and `modified:week`, and filters can be saved.
- Search understands OR and groups, can exclude paths, narrow results by folder, find similar files, and show facets and a date histogram. On Windows, typing "shell" in the palette offers the Explorer context menu of the selection.
- Ratings, comments and portable tags can be edited, shown as columns, searched and exchanged as XMP; companion files such as XMP sidecars can be hidden and travel with their main file.
- Files can be split into and joined from Total Commander compatible parts, duplicate selected files can be replaced with hard links, and on Windows recent disk changes can be read from the NTFS change journal and exported to CSV.
- Importing settings shows every change first, warns about entries that run programs, and can be undone.
- On Windows, FTP servers can be browsed from the address bar.
- An empty Network view explains when network discovery is off and how to turn it on.
- On Windows, a crash leaves an anonymized text report that is safe to attach to an issue.

## Changed

- Passwords typed into server addresses are hidden in the address bar, errors, notifications and logs.
- Index walks, folder sizes and file hashing run at low I/O priority, and folder sizes are computed by a scheduler that serves visible folders first.
- Archive previews and Linux WebP pictures are read in a short-lived helper process, sandboxed with bubblewrap when available.
- On Linux, Flit installed from a .deb or .rpm package points to the package manager for updates.
- The German, French, Spanish, Ukrainian and Simplified Chinese translations were proofread for consistent terms and plural forms.
- The README and Linux packages state that builds include UnRAR under its own license.

## Fixed

- Cancelled operations are recognised as cancelled in every interface language.
- Folder sizes cut short by Windows are marked as partial instead of being shown as complete.
