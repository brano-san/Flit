## Fixed

- Closing the last tab or all tabs in the last pane no longer brings those tabs back when Flit resumes the session. If no other windows remain, Flit opens Home on the next launch.
- On Linux, dormant automounts and unavailable network volumes stay visible and can be reconnected from the sidebar. Background folder sizing and indexing skip network mount points when scanning their parent folders.
- The Type column recognizes Linux executables, including Windows-local ELF files with no extension or a numeric suffix and executable files reported by WSL.
