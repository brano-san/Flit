## New

- Markdown previews show real tables with aligned columns, a bold header and wrapped cells that stay inside the pane, plus strikethrough, link labels, image captions, keyboard keys, footnotes, nested quotes and lists, indented code and hard line breaks.

## Changed

- The Connect to server dialog shows an example address from the start and turns it red only when the address is not understood.

## Fixed

- HDR videos (HDR10 and HLG, as recorded by recent phones) no longer look washed out in the preview pane on Windows and Linux.
- On Linux, emptying the trash no longer fails with "permission denied" on folders that contain read-only subfolders, such as Git repositories.
- When folder statistics are off for network locations, the sidebar tip no longer counts files on network mounts such as Linux SFTP shares, and "local drives only" thumbnails no longer treat those mounts as local.
