## New

- Settings → Context menu puts Add Custom Action first and lists the built-in actions right away. Custom actions take a description, a keyboard shortcut, a launch notification, file patterns, a selection count and file categories.
- Custom action commands accept `%f`, `%F`, `%n`, `%N`, `%d` and `%D` for paths, names and folders, each passed as its own program argument; `%%` is a literal percent sign. Commands saved by earlier versions keep every `%` they had literally.
- A custom action shortcut needs Ctrl or Alt, or is a function key, and cannot take a chord that a built-in command or another custom action already uses.
- On Windows, Show launch notification shows a Flit notification once the command has started. Custom actions start through the Windows shell, so commands such as `code`, batch files and programs registered by their installers are found as before.
- Context menus show icons for built-in actions, keep the opening actions together with Properties last, and have a draggable scrollbar.
- Properties has a fixed header with a close button and scrolls within the window; Escape closes it without applying changes, and so does a click outside unless attributes were changed.
- Dragged tabs follow the pointer inside the tab bar while the other tabs make room, and switch to split-view dragging outside it.

## Fixed

- Closing a context menu on a resize, a DPI change or a focus change no longer stops the window from handling that event.
- Linux Properties updates the creation, change and access dates when native metadata arrives instead of adding duplicate rows.
- Menu icons on Linux use symbols that the bundled font contains.
- Last Session on Linux resumes after an interrupted desktop shutdown, and the session is written to disk before Flit quits or its last window closes. A run that ended within its first minute still shows the recovery prompt, so a folder that crashes Flit is not reopened again and again.
