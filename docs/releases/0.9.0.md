## New

- On Linux, a folder can be opened as administrator from its context menu or the command palette. The tab is clearly marked, every file operation in it runs through one root helper started by pkexec after a single password prompt, deleting always asks for confirmation, and files written there stay owned by root. This is available only when Flit is installed system-wide (its files belong to root).
- On Linux, files dragged from archive managers such as File Roller, Engrampa and Ark, or from browsers, are saved into the folder under the pointer through the XdndDirectSave protocol on X11, with name conflicts handled as for other drops and failures shown in the status bar.
- On Linux, search can use one shared flit-indexd user service (systemd --user) for every Flit window. Packages and the install script ship the service but never enable it; enable it with `systemctl --user enable --now flit-indexd.socket` or `install.sh --index-service`. Without the service Flit keeps its own index as before.
- On Linux, text follows the desktop's subpixel (LCD) and hinting settings from GNOME, KDE or fontconfig, including slight hinting, and changes take effect without restarting Flit.
- On Windows, a new setting keeps Flit bookmarks and Quick access pinned folders in sync both ways. It is off by default, leaves Desktop, Downloads and other standard folders out of bookmarks, and never removes bookmarks when Quick access is reset or cleaned.

## Changed

- On Windows, Flit has a fixed app identity, and its shortcuts in the Start menu, on the taskbar and on the desktop are updated to match, so a pinned Flit button and its open windows share one taskbar button and jump list.
- On Linux, administrator prompts are offered only when Flit and pkexec are system programs owned by root. A Flit started from the home folder or an AppImage no longer asks for the administrator password and explains why.

## Fixed

- On Linux, temporary folders left by interrupted drops are cleaned up at start.
