## Changed

- File and folder context menus keep Open, Open in and the editing commands (Cut, Copy, Paste, Copy path, Create link, Rename, Delete) together in one block at the top.
- Properties show only the close button in the header until something is changed. OK and Cancel appear once an attribute or a permission is changed, and disappear again when the change is undone.
- An update that skips releases shows the notes of every skipped release, newest first.

## Fixed

- On Linux, a right click always gets the context menu of what was clicked. A menu that is still being built no longer opens after a later click, key press or leaving the window, so it can no longer run a command on the wrong item.
- Icons in an expanded submenu such as Open with now start exactly where the text of the top-level items starts.
- On Linux, clicking beside the Properties dialog no longer discards changed permissions.
