## Performance

- Large folders use less temporary memory when sorting by name. Filtering by extension or Unicode name and collapsing many groups are faster.
- Indexed searches allocate less memory for matches. Jumping deep into results on one volume can read the requested page directly, and the folder summary selects its top results with less sorting.
- ZIP listings stream the central directory and reuse names from the cached index.
- On Linux, directory scans do less work reading mount information, and copies that fall back to userspace reuse one buffer per operation.
- Single-file checksums, thumbnail caching, text previews, and saving sessions and tags use fewer temporary allocations.
